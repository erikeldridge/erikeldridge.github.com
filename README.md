# erikeldridge.github.com

## Set up

Install [Hugo](https://gohugo.io/installation/).

## Develop

1. Run test server: `hugo server`

## Deploy

Deployment is automated by a [GitHub Action](https://gohugo.io/host-and-deploy/host-on-github-pages/).

## Edit

Use Obsidian for convenient Markdown editing:

1. Install Obsidian
2. Create new vault from the `content` directory
3. Open vault settings
4. Install the [Community Install Manager plugin](https://github.com/skilletron/obsidian-automatic-installation-of-plugins). This persists a list of installed plugins in a way that doesn't require plugin source code to be commited to this repo.
5. Run the Manager to propagate installed plugins, as described in the [quickstart](https://github.com/skilletron/obsidian-automatic-installation-of-plugins#quick-start)
